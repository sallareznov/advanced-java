# Java avancé : projets

Ce dépôt contient les sujets des projets du cours de Java avancé.
Chaque sujet est dans son propre dossier.

| Projet | Dossier | En une phrase |
|---|---|---|
| Particules | [particles](particles/README.md) | Des particules colorées se déplacent en plein écran et rebondissent entre elles. |

D'autres sujets seront ajoutés ici.

## Règles communes à tous les projets

- Vous partez de zéro : aucun code de départ n'est fourni.
- Le code (noms de classes, de méthodes, de variables, commentaires) est écrit en anglais.
- JavaFX sert uniquement à afficher. Toute la logique est écrite en Java, dans des classes qui ne connaissent pas JavaFX.
